Install Kenglit
==============

1. Drag Kenglit into Applications.
2. Eject this disk.
3. First open (new Mac):

   Applications → right-click Kenglit → Open → Open

   If blocked: System Settings → Privacy & Security → Open Anyway

   Still blocked after download:
   xattr -cr /Applications/Kenglit.app
   then right-click → Open again.

4. Menu bar → On
5. Enable English + Vietnamese keyboards.

https://github.com/phcngyn99/Kenglit
