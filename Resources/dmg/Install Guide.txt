Install Kenglit
==============

1. Drag Kenglit into the Applications folder (on this disk).
2. Eject this disk image.
3. Open Finder → Applications → Kenglit.

First launch (Gatekeeper)
-------------------------
Ad-hoc signed beta builds are not notarized by Apple. macOS may show:

  "Apple could not verify Kenglit is free of malware..."

Do one of the following:

A. Right-click (or Control-click) Kenglit → Open → Open
B. System Settings → Privacy & Security → scroll to Security
   → Open Anyway (then confirm)

If it still blocks after a download:

  xattr -cr /Applications/Kenglit.app
  Then use right-click → Open again.

After install
-------------
- Menu bar icon appears (mint K keycap template).
- Turn On from the menu.
- Settings… to pick English apps.
- English + Vietnamese input sources must be enabled in
  System Settings → Keyboard → Input Sources.

Version: see Settings → ⓘ About (not the file name).
